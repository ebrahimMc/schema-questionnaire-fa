# پرسش‌نامه طرحواره YEMSQ

نسخه فارسی و راست‌به‌چپ ۷۵ سؤالی، بر اساس اسکن «تست طرحواره.pdf» و «فایل تکمیلی طرحواره.pdf» ارائه‌شده توسط کاربر. فونت وزیرمتن همراه سایت قرار دارد؛ مجوز در fonts/OFL.txt است.

## اجرا و GitHub Pages

محتوای این مخزن یک سایت ایستا و مستقل است. با فرمان زیر پیش‌نمایش محلی را اجرا کنید و http://localhost:4173 را باز کنید:

```sh
python3 -m http.server 4173
```

برای GitHub Pages، شاخه main و مسیر / را به‌عنوان مسیر انتشار انتخاب کنید. حساب، کلید، پایگاه داده یا مرحله build لازم نیست.

## نمره‌گذاری

۷۵ سؤال به ۱۵ گروه متوالی پنج‌سؤالی تقسیم می‌شوند. میانگین هر مقیاس برابر جمع پنج پاسخ تقسیم بر ۵ است. طبق فایل راهنما، معکوس‌سازی وجود ندارد. میانگین بالاتر از ۳ و بالاترین میانگین بین مقیاس‌ها جداگانه نمایش داده می‌شوند. دقیقاً ۳ بالاتر از ۳ نیست. تمام بالاترین‌های مشترک نمایش داده می‌شوند؛ اگر همه برابر باشند، نتیجه همین برابری را بیان می‌کند. نتیجه تشخیص بالینی نیست.

نمودار فایل تکمیلی ۱۸ طرحواره دارد؛ آزمون و جدول فقط ۱۵ مقیاس دارند. برای مقیاس بدون سؤال نمره تولید نمی‌شود. فاصله‌گذاری و رسم‌الخط متن اسکن در تایپ یکدست شده است.

## داده‌ها

پاسخ‌ها فقط در localStorage مرورگر می‌مانند و به سرور ارسال نمی‌شوند. دکمه پاک‌کردن، پاسخ‌های همین آزمون را حذف می‌کند. خروجی JSON شامل پاسخ‌ها و تمام نمره‌هاست؛ چاپ و ذخیره PDF نتیجه نیز فراهم است.

## فایل‌ها و بررسی

متن سؤال‌ها در data.js، منطق در app.js، طراحی در style.css و صفحه اصلی در index.html است.

نگاشت هر ۱۵ مقیاس، کمینه و بیشینه، مرز ۳ و ۳٫۲، نمره‌های مساوی و رد ورودی نامعتبر/ناقص با آزمون محاسباتی بررسی شدند. در مرورگر، انتخاب تمام ۷۵ پاسخ، اعتبارسنجی پاسخ ناقص، نتیجه، و حفظ پاسخ‌ها پس از بارگذاری دوباره بررسی شدند.
